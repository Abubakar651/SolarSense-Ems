# Fonts

`inter-latin-variable.woff2` is the Latin subset of **Inter** (variable weight, v20) from Google Fonts:
`https://fonts.gstatic.com/s/inter/v20/UcC73FwrK3iLTeHuS_nVMrMxCp50SjIa1ZL7.woff2`.

It is committed so builds are reproducible and offline, and so the app renders the exact same glyphs as
`frontend/design/index.html` (the pixel-parity reference). Inter is licensed under the
[SIL Open Font License 1.1](https://openfontlicense.org/).
